# Logeswaran M — Portfolio

A responsive, modern dark-theme portfolio built with plain HTML, CSS, and JavaScript. No build tools or dependencies are required.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
2. Replace the LinkedIn URL with your actual profile URL.
3. Add your latest resume PDF at `assets/LogeswaranM_Resume.pdf` (create the `assets` folder if needed).
4. Verify the degree title, institution, dates, project descriptions, and skills. Remove anything that does not accurately reflect your experience.
5. Add verified public repository links to the project cards where appropriate. Do not publish confidential employer or government project details.

## Run locally
Open `index.html` in a browser. For a local server, run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Publish to GitHub Pages
1. Download and extract this package.
2. Copy `index.html` and `README.md` into the root of `Logeswaran-M-Portfolio`, preserving any existing resume/assets you want to keep.
3. Commit and push to the repository's publishing branch (commonly `main`).
4. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, then choose the branch and `/ (root)`.
5. Wait for the Pages deployment to finish and open the published URL.

## Notes
- The resume link expects `assets/LogeswaranM_Resume.pdf`.
- This is a starter implementation prepared from the known career details. Review all copy and links before publishing.
